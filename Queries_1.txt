C = a.

C = a,
B = d.

C unifies with a and B unifies with d

28 ?- edge(C,B) = edge(a,d).
C = a,
B = d.

C unifies with a and B unifies with d.

29 ?- edge(A,f(g,h)) = edge(a,B).

A unifies with a and B unifies with f(g,h).

30 ?- edge(A,A) = edge(b,c).
false.

A cannot be both b and c, so unification fails.

31 ?- edge(A,A) = edge(b,b).
A = b.

Both occurrences of A unify with b.

32 ?- A = B, B = f.
A = B, B = f.

A and B are linked, then both unify with f.

33 ?- A = B, B = f, A = e.
false.

A is already f, so it cannot also unify with e.
